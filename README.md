# Parking-Management-System

## Project Description
Parking Management System using C++ and DSA

The system has a total capacity of 200 vehicles, with separate slots for bikes (1–100) and cars (101–200).

## Technologies Used
- C++
- Object-Oriented Programming
- File Handling

## Data Structures Used
1. Doubly Linked List
2. Min Heap (Separate for Bikes and Cars)
3. Merge Sort
4. Hash Table with Separate Chaining
5. Circular Queue
6. Binary Search Tree
7. AVL Tree
8. Stack

## Features
- Park vehicles
- Exit vehicles and generate bills
- Search vehicles by plate number
- Display available parking slots
- Display occupied parking slots
- Sort vehicle records
- Manage waiting queue
- Calculate total revenue
- Maintain parking history
- Save and load parking records
- Display recent bills
- Use system date and time for vehicle entry and exit
